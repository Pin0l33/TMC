# TMC — Hardware

**Teknical May Cry (TMC)**  
Proyecto Integrador Anual (P.I.A.) — 2026  
Laboratorio de Programación (LPR)

---

## 1. Descripción general

Este apartado contiene la documentación correspondiente al área de hardware del proyecto **Teknical May Cry (TMC)**.

Su propósito es centralizar y organizar los recursos técnicos, la información de los componentes, los diseños, los esquemas y las evidencias relacionadas con el desarrollo de la parte física del proyecto.

## 2. Estructura del directorio

La carpeta se encuentra organizada de la siguiente manera:

| Directorio / Archivo | Descripción |
|---|---|
| `informe/` | Informe técnico del desarrollo de hardware. |
| `componentes/` | Información y características de los componentes utilizados. |
| `esquemas/` | Diagramas y representaciones de conexiones. |
| `codigo/` | Código relacionado con el control del hardware, si corresponde. |
| `evidencias/` | Fotografías y registros del proceso de desarrollo. |

## 3. Documentación técnica

La documentación de esta sección permite registrar las distintas etapas del desarrollo, desde la selección de componentes hasta el diseño, la implementación y las pruebas del hardware.

Se busca mantener un registro organizado que facilite la comprensión, el mantenimiento y la evaluación técnica del sistema.

## 4. Relación con el software

El área de hardware forma parte del desarrollo integral de TMC y complementa el área de software.

Ambas secciones mantienen su documentación y recursos organizados de manera independiente dentro del repositorio principal.

## 5. Estado del desarrollo

El contenido de este apartado se actualizará conforme avance el desarrollo del hardware, incorporando la documentación, los recursos técnicos y las evidencias correspondientes.

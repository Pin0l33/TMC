## [1.0.0] - 2026-10-01

### Added
- Se desarrolló la página web del proyecto y se incorporó información del equipo docente.
- Se creó el minijuego inspirado en FNAF (FNAE), con escenas, transiciones y una demo de la primera noche.
- Se incorporó la primera implementación de la base de datos.
- Se implementó un nuevo mapa para el juego.
- Se agregaron elementos gráficos en pixel art, como la moneda, el cursor y el engranaje.
- Se avanzó con las aulas 1 y 2 del escenario, incluyendo distintos modelos de mesas y sillas.
- Se incorporaron animaciones para la moneda.

### Changed
- Se modificó y mejoró la estética de la página web, incluyendo ajustes de colores.
- Se agregó el inicio de sesión y se realizaron ajustes en el registro de usuarios.
- Se mejoró el HUD del juego.
- Se incorporó una nueva animación de movimiento del personaje.
- Se agregaron nuevas zonas al mapa, puntos de aparición (spawn points) y colliders.
- Se incorporaron el menú de pausa y el menú de opciones.
- Se agregó la posibilidad de cambiar el idioma del juego.
- Se realizaron mejoras y correcciones en la documentación técnica del proyecto.

### Fixed
- Se corrigió el nombre de la tabla SQL utilizado en el registro de usuarios.
